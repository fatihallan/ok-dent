# OK Dent Starter

İlk proje iskeleti: Next.js + Supabase Auth entegrasyonuna hazır yapı.

## Kurulum

1. Node.js 20+ kurulu olmalı.
2. Terminalde proje klasöründe:
   npm install
3. `.env.example` dosyasını `.env.local` olarak kopyalayın ve Supabase bilgilerini girin.
4. `npm run dev`
5. Ana sayfa: http://localhost:3000
6. Admin: http://localhost:3000/admin

## Supabase

Supabase projesinde Authentication > Providers > Email açık olmalı.
İlk admin kullanıcısını Supabase Authentication > Users bölümünden oluşturabilirsiniz.
